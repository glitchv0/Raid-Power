1 · In-game buff bars

The bar shows only what you are responsible for, so each class sees its own version. Every tile is a secure click button: left-click casts on the next person who needs it (group/greater version when it's worth it), right-click casts the single-target version, and hovering opens the player list. The coloured underline is the status. The badge counts players missing it. The number is the shortest time left. The Smart Buff button (bindable to one key) works through everything you owe, most urgent first.

2 · Main window (/rp)

This is where buffs get split between players. Changes sync to everyone in the group running RaidPower. The raid leader and assists can edit every row; other players can edit only their own (and anyone who turns on "Free assignment"). Click the sidebar items and matrix cells to try it.
